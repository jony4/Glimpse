# Glimpse 0.1.2

面向 macOS Apple Silicon（ARM64）。本版增加基础文本编辑、扩展文件格式支持，并修复文件树点击抖动。

## 更新内容

- 普通 UTF-8 文本和 Markdown 源码支持基础编辑、撤销/重做、Save / ⌘S；保存保留撤销历史。
- 未保存内容不会被自动刷新覆盖；关闭标签、窗口或项目时提供放弃确认。保存检测磁盘内容冲突，使用临时文件替换，避免直接截断原文件。
- 修复目录展开、加载及吸顶目录收起时的行位置抖动。
- 增加 Java、SQL、Make 高亮；补充 Vue/XML、Cython、着色器及常见配置格式的基础源码高亮。
- 增加 EXR/HDR 的 SDR 图片预览；大型 SVG 按比例缩小预览，避免因画布过大直接拒绝打开。
- 点文件按内容处理；文本正常查看/编辑，无法解码的点文件（如 .DS_Store）提供最多前 64 KiB 的只读十六进制/ASCII 预览。
- 默认侧栏宽度调整为 320px，仍可拖拽；调整 Dock 图标的视觉大小和对比度。
- 保持原有界面布局，本版不包含 Liquid Glass 改造。

## 下载与安装

下载 Glimpse-0.1.2-macos-arm64.dmg，将 Glimpse.app 拖到 Applications。
仅提供 Apple Silicon / ARM64，不包含 Intel 版本；随包提供 SHA-256 校验文件。
应用使用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证。

## 验证与限制

格式检查、严格 Clippy、49 项测试、debug 及 ARM64 release 构建通过。
文件格式抽样共 19 类、81 个实文件，全部通过读取/解码检查；不等同于逐类原生界面验证。

编辑仅支持已有文件，无新建、另存为、自动保存或强制退出后的草稿恢复。
文本上限 2 MiB。Vue/XML 等别名仅为基础高亮；EXR/HDR 不提供 HDR 色彩管理。
Office、PDF、DWG、Blender 等专用预览尚未实现。完整范围见 docs/file-format-support.md，验证细节见 docs/verification.md。
