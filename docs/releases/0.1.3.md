# Glim 0.1.3

**AI 时代的全能查看器。** Glimpse 正式更名为 Glim，界面、命令行与应用包统一使用新名称，兼容旧版换行设置。

## 新增与改进

- 普通文本自动保存，保留 ⌘S；用低对比小点标记待保存修改。移除底部状态栏和无效的代码导航菜单。
- 顶部集中提供持久化换行开关与 Markdown 预览 / 原文切换；Files / Git 再次点击可收起侧栏，目录空白处支持添加工作区文件夹。
- 扩展 Ruby、Jinja、Dockerfile、`.npmrc` 等语言及配置文件着色；完整覆盖和渲染层级见 README。
- 文本编辑预算提升至 8 MiB。大文件按约 256 KiB 分页，完整只读加载需确认且限制在 64 MiB / 100 万行；超长行使用虚拟列表分段显示。
- safetensors 提供模型头部、张量数量、参数数量、精度和元数据预览，不读取权重；头部最多 8 MiB，张量列表最多 2,000 项。
- Git 新增分支创建、切换、重命名、安全删除、合并，Fetch / Pull / Push / Sync / Publish，以及 Stash / Apply Stash。Pull 仅允许快进，不强推、不自动改写历史。
- Git Changes 下新增默认收起的 Graph，显示分支连线、提交与引用；支持提交详情和补丁查看。
- 修正图片居中、目录箭头抖动和大文件横向宽度；错误提示移至右下角，扫描主目录时跳过无权访问的子目录。

## 安装

适用于 **macOS Apple Silicon（arm64）**。

- `Glim-0.1.3-macos-arm64.dmg`
- `Glim-0.1.3-macos-arm64.dmg.sha256`

打开 DMG，将 `Glim.app` 拖到 Applications。旧版使用 `Glimpse.app` 名称；退出旧版后保留备份，再使用新应用。

应用使用 ad-hoc 签名，尚无 Developer ID 签名与 Apple 公证。首次打开可能需要在系统设置 → 隐私与安全性中允许。SHA-256 文件可验证下载完整性。

## 范围与限制

本版不提供 clone、force push、rebase、reset、cherry-pick 或三路合并编辑器。Git 网络操作沿用本机凭据；Graph 最多读取 1,000 个提交。分页模式只读，不提供全文搜索；safetensors 预览不等同于完整模型校验。详见 README。

## 验证

格式、Clippy、完整测试（53 项）和构建通过。ARM64 DMG、SHA-256、应用签名及安装启动检查通过；已实机查看 Markdown 与居中图片预览。受 macOS 辅助访问权限限制，自动点击、拖动及键盘交互未覆盖。详见 [验证记录](../verification-0.1.3.md)。
